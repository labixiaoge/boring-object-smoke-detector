A one-line review of the smoke detector, written for make.fun's "The Most Boring Object, Reviewed in One Line" bounty. The program writes the review — 113 characters, one line — to `/output/entry.txt`.

> The smoke detector ignored five years of burnt dinners, then woke me at 3 a.m. to complain its battery was tired.

## Run it

```sh
node main.ts
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no randomness, no secrets — the review is a constant in `main.ts`, validated (1–200 characters, single line) before it is written.
